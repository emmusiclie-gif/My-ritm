# «Мой ритм» — Android

Нативная версия приложения находится в папке `android/`. PWA-файлы в корне репозитория оставлены без изменений.

## Основа

- Kotlin + Jetpack Compose — интерфейс.
- Room / SQLite — локальная база данных.
- Данные хранятся во внутренней базе приложения; интернет-разрешение не запрашивается.
- Минимальная версия Android: 8.0 (API 26).
- Цвета: тёплый бежевый, шалфейный и мягкий зелёный.

## Структура

- `app/src/main/java/com/moyritm/app/MainActivity.kt` — главный экран и нижняя навигация.
- `data/Entities.kt` — таблицы базы данных.
- `data/AppDao.kt` — запросы и операции с таблицами.
- `data/AppDatabase.kt` — создание локальной базы Room.
- `ui/theme/Theme.kt` — палитра приложения.
- `app/schemas/` — JSON-схемы Room, генерируемые при сборке.

## Таблицы базы данных

| Таблица | Что хранит |
|---|---|
| `stick_entries` | время записи, тип стика, заметка |
| `medications` | название лекарства, дозировка, единица и активность |
| `medication_schedules` | время и дни приёма |
| `medication_intakes` | запланированный приём и отметка «принято/пропущено» |
| `food_products` | локальный каталог продуктов и значения на 100 г |
| `food_entries` | съеденная порция и КБЖУ/сахар этой порции |
| `water_entries` | объём воды и тип ёмкости |
| `app_settings` | цель воды и параметры напоминаний |

## Как получить APK без компьютера

После изменения файлов в папке `android/` GitHub Actions автоматически запускает сборку.

1. Открой репозиторий на GitHub.
2. Перейди во вкладку **Actions**.
3. Открой последний запуск **Build Android APK**.
4. Дождись зелёной отметки успешной сборки.
5. Внизу страницы скачай артефакт **my-ritm-debug-apk**.
6. Распакуй ZIP на телефоне и открой `app-debug.apk` для установки.

Если запуск не появился автоматически, открой **Actions → Build Android APK → Run workflow**.

Это отладочный APK для проверки на телефоне. Он ещё не подписан ключом релизной версии и пока не предназначен для публикации в Google Play.

## Сборка на компьютере

Если появится компьютер с Android Studio, открой в Android Studio именно папку `android/`, установи JDK 17 и Android SDK Platform 36, затем выполни **Build → Build APK(s)**. Для локальной командной сборки используется Gradle 8.13:

```bash
gradle :app:assembleDebug
```
